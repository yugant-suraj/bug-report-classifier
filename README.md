# bug-report-classifier
Machine learning tool for classifying performance-related bug reports using TF-IDF and Linear SVM. Includes baseline comparison with Naive Bayes and evaluation across multiple datasets.
# Bug Report Classification using TF-IDF and Linear SVM

## Overview
This project builds a machine learning tool to classify performance-related bug reports in deep learning frameworks.

## Features
- TF-IDF feature extraction
- Naive Bayes baseline
- Linear SVM improved model
- Bigram + unigram features
- Class imbalance handling

## Datasets
- Caffe
- MXNet
- Keras
- PyTorch
- TensorFlow

## Results
Linear SVM significantly outperforms Naive Bayes in F1-score across all datasets.
